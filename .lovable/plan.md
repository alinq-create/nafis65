
# تعديل واجهة دخول الطالبة - إزالة رمز الاختبار وإضافة اختيار المادة

## ملخص التغييرات
إزالة حقل "رمز الاختبار" بالكامل من واجهة الطالبة واستبداله بقائمة اختيار المادة. عند الدخول، يبحث النظام تلقائيًا عن الاختبارات المنشورة المطابقة للمادة والفصل. إذا وُجد اختبار واحد يبدأ مباشرة، وإذا وُجد أكثر من اختبار تظهر صفحة اختيار بسيطة.

---

## التفاصيل

### 1. تعديل صفحة دخول الطالبة (`StudentEntry.tsx`)

- حذف حقل "رمز الاختبار" ومتغير `examCode` بالكامل
- إضافة حقل **المادة** كقائمة اختيار تحتوي: رياضيات، علوم، لغة عربية
- تعديل شرط التحقق ليكون: اسم الطالبة + رقم الفصل + المادة
- إضافة حالة جديدة: عرض قائمة اختيار الاختبار عند وجود أكثر من اختبار منشور
- المنطق الجديد:
  - إذا لم يوجد اختبار: رسالة "لا يوجد اختبار متاح الآن لهذه المادة والفصل"
  - إذا وجد اختبار واحد: انتقال مباشر لصفحة الاختبار
  - إذا وجد أكثر من اختبار: عرض قائمة بأسماء الاختبارات للاختيار منها

### 2. تعديل الدالة الخلفية (`student-exam-access/index.ts`)

- إزالة معامل `examCode` من المدخلات
- إضافة معامل `subject` (المادة) بدلًا منه
- تعديل الاستعلام ليبحث بالشروط:
  - `status = 'منشور'`
  - `subject = المادة المختارة`
  - `الفصل ضمن target_classes`
- إرجاع مصفوفة اختبارات بدلًا من اختبار واحد
- إذا طُلب اختبار محدد (`examId`)، يُرجع أسئلته مباشرة

### 3. بدون تغيير

- صفحة أداء الاختبار (`TakeExam.tsx`): لا تغيير، تستقبل نفس البيانات
- صفحة تأكيد الإرسال (`SubmissionConfirmation.tsx`): لا تغيير
- المسارات في `App.tsx`: لا تغيير

## تفاصيل تقنية

### الدالة الخلفية - المنطق الجديد

الدالة تقبل أحد نمطين:

**النمط الأول** - البحث عن اختبارات متاحة:
```
المدخلات: { studentName, classNumber, subject }
المخرجات: { exams: [{ id, exam_name }] } أو { examId, examName, questions: [...] }
```

**النمط الثاني** - جلب أسئلة اختبار محدد:
```
المدخلات: { studentName, classNumber, subject, examId }
المخرجات: { examId, examName, questions: [...] }
```

### واجهة الطالبة - الحالات

| الحالة | ما يظهر |
|--------|---------|
| البداية | نموذج الدخول (اسم + فصل + مادة) |
| لا يوجد اختبار | رسالة تنبيه عربية |
| اختبار واحد | انتقال مباشر لصفحة الاختبار |
| عدة اختبارات | قائمة بأسماء الاختبارات مع زر اختيار |
