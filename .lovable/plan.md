

# تثبيت صلاحيات النظام

## الوضع الحالي

بعد مراجعة الكود الحالي، الصلاحيات الأساسية موجودة في قاعدة البيانات (RLS) لكن الواجهات لا تعكس كل المطلوب. إليك ما يحتاج تعديل:

---

## التعديلات المطلوبة

### 1. لوحة المديرة - إضافة صفحات جديدة

**الحالي:** المديرة ترى فقط إحصاءات مبسطة + إدارة المعلمات.

**المطلوب:**
- صفحة **عرض المحاولات المعتمدة**: تعرض نتائج الطالبات بعد اعتماد المعلمة فقط (الحالة = "معتمد")، مع إمكانية التصفية حسب المادة والفصل
- صفحة **التحليلات العامة**: إحصاءات شاملة لجميع المواد والفصول (نسب النجاح، متوسط الدرجات، أداء كل فصل)
- تحديث القائمة الجانبية بإضافة الروابط الجديدة

### 2. لوحة المعلمة - إضافة التحليلات

**الحالي:** المعلمة تراجع المحاولات وتعتمد النتائج، لكن لا يوجد تحليل بعد الاعتماد.

**المطلوب:**
- صفحة **تحليلات المعلمة**: تظهر بعد اعتماد النتائج، تشمل:
  - متوسط الدرجات لكل اختبار
  - نسبة الإجابات الصحيحة لكل سؤال
  - مقارنة أداء الفصول
- تقييد عرض الفصول فقط ضمن النطاق المحدد من المديرة (موجود جزئيًا)

### 3. تعزيز قيود الفصول للمعلمة

**الحالي:** المعلمة تختار الفصول من نطاقها عند إنشاء الاختبار.

**المطلوب:**
- التأكد أن المعلمة لا ترى محاولات من فصول خارج نطاقها
- التأكد أن التحليلات تعرض فقط بيانات فصولها

### 4. تمييز المحاولات المعتمدة وغير المعتمدة

**الحالي:** المعلمة ترى كل المحاولات في صفحة واحدة.

**المطلوب:**
- فصل المحاولات إلى: "بانتظار الاعتماد" و"معتمدة"
- المديرة ترى المعتمدة فقط
- المعلمة ترى الكل مع تبويبات

### 5. واجهة الطالبة

**الحالي:** الطالبة تدخل بالاسم + الفصل + رمز الاختبار ولا ترى النتيجة. --- لا تغيير مطلوب.

## تفاصيل تقنية

### صفحة المديرة - المحاولات المعتمدة (`AdminAttempts.tsx`)
- استعلام `student_attempts` مع شرط `status = 'معتمد'`
- ربط مع جدول `exams` لعرض اسم الاختبار والمادة
- فلاتر: حسب المادة، حسب الفصل
- عرض: اسم الطالبة، الفصل، الاختبار، الدرجة المعتمدة

### صفحة المديرة - التحليلات (`AdminAnalytics.tsx`)
- متوسط الدرجات لكل مادة
- متوسط الدرجات لكل فصل
- عدد المحاولات لكل اختبار
- رسوم بيانية باستخدام مكتبة `recharts` الموجودة

### صفحة المعلمة - التحليلات (`TeacherAnalytics.tsx`)
- تعرض فقط بيانات اختبارات المعلمة
- تصفية حسب الفصول المسموحة فقط
- نسبة الإجابات الصحيحة لكل سؤال
- متوسط الدرجات لكل فصل

### تعديل القائمة الجانبية
- المديرة: إضافة "المحاولات المعتمدة" و"التحليلات"
- المعلمة: إضافة "التحليلات"

### أمان قاعدة البيانات (RLS)
- السياسات الحالية صحيحة: المديرة ترى كل شيء، المعلمة ترى اختباراتها فقط
- لا حاجة لتعديل سياسات RLS الحالية لأنها تغطي المطلوب بالفعل
