
# تحسين واجهة مراجعة إجابات الطالبة بالألوان والوضوح البصري

## الملف المعدل: `src/pages/teacher/ReviewAttempts.tsx`

لا حاجة لتعديل Edge Function أو قاعدة البيانات. التغيير كله في طريقة العرض.

## التعديلات المطلوبة

### 1. تحديث دالة `getOptionStyle`
- الإجابة الصحيحة: إطار أخضر + خلفية خضراء فاتحة (كما هو حاليا)
- إجابة الطالبة الخاطئة: تغيير من أزرق الى **إطار أحمر + خلفية حمراء فاتحة**
- الخيارات غير المختارة: تبقى بدون تمييز

### 2. تحديث عرض الخيارات (الأسئلة النصية MCQ)
لكل خيار يضاف:
- الإجابة الصحيحة: أيقونة **CheckCircle** خضراء (موجودة) + نص "إجابة صحيحة" إذا كانت هي نفسها إجابة الطالبة
- إجابة الطالبة الخاطئة: أيقونة **XCircle** حمراء + نص "إجابة الطالبة"

### 3. إضافة سطر ملخص أسفل الخيارات
بعد قائمة الخيارات مباشرة، يظهر سطران واضحان:
```text
إجابة الطالبة: (ج)
الإجابة النموذجية: (د)
```
مع استخدام `optionLabels` للترجمة العربية.

### 4. تحسين عرض حالة "لم تجب"
- الرسالة تظهر لكلا نوعي الأسئلة (نصية ومصورة) عند عدم وجود إجابة
- الإجابة الصحيحة تبقى مميزة بإطار أخضر

### 5. تحسين عرض الأسئلة المصورة
- الصورة تبقى كما هي في الأعلى
- أسفلها: سطر ملخص إجابة الطالبة والإجابة الصحيحة مع ألوان واضحة (أخضر/أحمر)
- إضافة أيقونات للتوضيح
