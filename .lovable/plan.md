

# إعادة تصميم واجهة مراجعة المحاولات

## الملخص
إعادة بناء واجهة مراجعة محاولة الطالبة بالكامل لتكون تجربة مراجعة سؤال بسؤال (بدلا من قائمة طويلة في Dialog)، مع تصميم هادئ وواضح يناسب البيئة التربوية.

## التعديلات

### الملف الوحيد المعدل: `src/pages/teacher/ReviewAttempts.tsx`

لا حاجة لتعديل Edge Function (البيانات تأتي كاملة بالفعل). التغيير كله في واجهة العرض.

### التصميم الجديد

**عند فتح محاولة طالبة** يتحول العرض من Dialog الى صفحة مراجعة كاملة داخل نفس الـ layout تحتوي:

#### 1. رأس الصفحة (Header)
- اسم الاختبار + اسم الطالبة + الفصل
- مؤشر التقدم: "السؤال 3 من 17"
- شريط تقدم بصري (Progress Bar)

#### 2. عرض سؤال واحد في كل مرة
- استخدام state لـ `currentQuestionIndex` للتنقل بين الأسئلة
- **سؤال نصي**: نص السؤال بحجم واضح + 4 خيارات:
  - الإجابة الصحيحة: إطار أخضر + أيقونة صح
  - إجابة الطالبة (إن كانت مختلفة): إطار أزرق
  - بدون لون أحمر (لتقليل التوتر)
- **سؤال مصور**: عرض الصورة المقصوصة باستخدام نفس طريقة `TakeExam.tsx` (background-size/position)
  - تحتها: إجابة الطالبة والإجابة الصحيحة
- **سؤال بدون إجابة**: رسالة "لم تجب الطالبة على هذا السؤال"

#### 3. قسم التقييم (داخل بطاقة السؤال)
- الدرجة التلقائية بخط رمادي
- حقل رقمي لتعديل الدرجة (0 الى 1) مع spinner
- القيمة الافتراضية = الدرجة التلقائية

#### 4. التنقل بين الأسئلة
- زر "السابق" وزر "التالي" أسفل البطاقة
- نفس نمط التنقل في `TakeExam.tsx`

#### 5. شريط اعتماد ثابت (Sticky Footer)
- مجموع الدرجات الحالي (مجموع الدرجات المعدلة لكل سؤال)
- زر "اعتماد النتيجة" رئيسي
- عند الضغط: نافذة تأكيد بسيطة (AlertDialog)
- بعد الاعتماد: تحديث الحالة بدون إعادة تحميل

### التغييرات التقنية

- حذف Dialog واستبداله بعرض شرطي (إذا كانت `selectedAttempt` موجودة يظهر عرض المراجعة، وإلا تظهر قائمة المحاولات)
- إضافة state: `currentQuestionIndex` و `questionScores` (مصفوفة درجات لكل سؤال)
- عرض الصور المصورة بنفس طريقة `TakeExam.tsx` مع `background-size` و `background-position` ومسار `shared/`
- الألوان: أخضر للصحيحة، أزرق لإجابة الطالبة، بدون أحمر
- AlertDialog للتأكيد قبل الاعتماد
- حساب المجموع من `questionScores` بدلا من حقل واحد
- الخط والتصميم عربي RTL بالكامل
