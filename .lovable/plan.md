
# إضافة زر التحليلات في قائمة الاختبارات

## المشكلة
صفحة قائمة الاختبارات (`CreateExam.tsx`) لا تحتوي على زر للانتقال إلى صفحة تحليلات الاختبار. حالياً عمود "إجراءات" يعرض فقط زر "نشر" أو "إغلاق".

## الحل
إضافة زر تحليلات (أيقونة 📊) في عمود الإجراءات لكل اختبار، بحيث يأخذ المعلمة مباشرة إلى صفحة تحليلات ذلك الاختبار.

## التغييرات

### ملف واحد: `src/pages/teacher/CreateExam.tsx`

1. **استيراد أيقونة BarChart3** من lucide-react بجانب أيقونة Plus الموجودة
2. **إضافة زر التحليلات** في عمود الإجراءات لكل اختبار (بجانب أزرار نشر/إغلاق)
   - أيقونة BarChart3 داخل زر صغير
   - عند النقر ينتقل إلى `/teacher/exam-analytics/{examId}`
   - يظهر لجميع الاختبارات بغض النظر عن حالتها (مسودة، منشور، مغلق)

### التفاصيل التقنية
- إضافة `BarChart3` لاستيراد lucide-react في السطر 11
- إضافة زر جديد في div الإجراءات (السطور 103-114) يظهر دائماً:
  ```
  <Button size="sm" variant="ghost" onClick={() => navigate(`/teacher/exam-analytics/${exam.id}`)}>
    <BarChart3 className="h-4 w-4" />
  </Button>
  ```
- لا تعديل على أي منطق آخر
