

# ملف الطالبة الأداء - Student Performance Profile

## الملخص
إنشاء صفحة ملف أداء لكل طالبة تعرض للمعلمة نظرة شاملة عن مستوى الطالبة عبر جميع الاختبارات المعتمدة.

## الملفات

### 1. ملف جديد: `src/pages/teacher/StudentProfile.tsx`
صفحة ملف الطالبة التفصيلي.

### 2. ملف جديد: `src/pages/teacher/StudentsList.tsx`
صفحة قائمة الطالبات (للوصول لملف كل طالبة).

### 3. تعديل: `src/App.tsx`
إضافة routes جديدة:
- `/teacher/students` - قائمة الطالبات
- `/teacher/students/:studentName/:classNumber` - ملف الطالبة

### 4. تعديل: `src/components/layout/DashboardLayout.tsx`
إضافة رابط "الطالبات" في القائمة الجانبية للمعلمة.

## التصميم

### صفحة قائمة الطالبات (`StudentsList.tsx`)
- جلب جميع المحاولات المعتمدة لاختبارات المعلمة
- تجميع الطالبات حسب الاسم + رقم الفصل (بما أنه لا يوجد جدول طالبات منفصل)
- عرض: الاسم، الفصل، عدد الاختبارات، متوسط الدرجة
- زر "عرض الملف" للانتقال لصفحة الملف التفصيلي
- بحث بالاسم وفلترة بالفصل

### صفحة ملف الطالبة (`StudentProfile.tsx`)

#### أ) رأس الصفحة - ملخص عام
| البيان | المصدر |
|--------|--------|
| اسم الطالبة | من URL parameter |
| الفصل | من URL parameter |
| عدد الاختبارات | عدد المحاولات المعتمدة |
| المتوسط العام | متوسط (approved_score / total_questions) * 100 |
| آخر درجة | أحدث محاولة معتمدة |

#### ب) مؤشرات الأداء (4 بطاقات)
- نسبة الإجابات الصحيحة (%) - من student_answers
- نسبة الأسئلة غير المجابة (%)
- مؤشر الاتجاه: تحسن / مستقر / تراجع (مقارنة آخر 3 اختبارات بأول 3)
- المستوى العام: ممتاز (>=80%) / جيد (>=60%) / يحتاج دعم (<60%)

#### ج) نقاط القوة
- أنواع الأسئلة ذات الأداء العالي (اختيار متعدد، صح/خطأ، مقالي)
- حساب نسبة الصواب لكل نوع سؤال
- عرض الأنواع التي نسبة صوابها اعلى من 70%

#### د) نقاط الضعف
- أنواع الأسئلة ذات الأداء المنخفض (اقل من 50%)
- الأنواع ذات نسبة عدم الإجابة العالية
- عرض بطاقات بألوان هادئة

#### هـ) سجل الاختبارات (جدول)
| العمود | الوصف |
|--------|-------|
| اسم الاختبار | من exams |
| التاريخ | submission_time |
| الدرجة | approved_score / total |
| النسبة | (%) |

#### و) توصيات ذكية (نصية - بدون ذكاء اصطناعي)
قواعد بسيطة:
- اذا نسبة عدم الإجابة > 30%: "تحتاج الطالبة لتشجيع على محاولة جميع الأسئلة"
- اذا نوع سؤال معين ضعيف: "تحتاج دعم في أسئلة [النوع]"
- اذا مؤشر الاتجاه تحسن: "تظهر الطالبة تحسناً ملحوظاً في الاختبارات الأخيرة"
- اذا المتوسط ممتاز: "أداء متميز - يمكن تكليفها بمهام إثرائية"

## مصدر البيانات
- `student_attempts` (status = "معتمد") مع ربطها بـ `exams` للمعلمة الحالية
- `student_answers` لتحليل الإجابات التفصيلية
- `exam_questions` + `question_bank` + `text_question_bank` لمعرفة أنواع الأسئلة
- جميع الحسابات client-side
- لا حاجة لجداول جديدة

## ملاحظة عن تعريف الطالبة
لا يوجد جدول طالبات في قاعدة البيانات. الطالبة تُعرف بـ (`student_name` + `class_number`) من جدول `student_attempts`. لذلك سيتم استخدام هذين الحقلين كمعرف في URL.

## التفاصيل التقنية

### Routes في `App.tsx`
```text
/teacher/students          -> StudentsList (محمي بصلاحية teacher)
/teacher/students/:name/:class -> StudentProfile (محمي بصلاحية teacher)
```

### رابط في الشريط الجانبي
إضافة عنصر جديد في `teacherLinks` بـ `DashboardLayout.tsx`:
```text
{ path: "/teacher/students", label: "الطالبات", icon: Users }
```
يوضع بعد رابط "المحاولات".
