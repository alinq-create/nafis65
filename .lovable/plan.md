

# تطوير تقرير طباعة تحليلات الاختبار

## الملخص
تحسين صفحة تقرير الاختبار (`ExamReport.tsx`) بحيث تتضمن ترويسة أكاديمية كاملة مع شعار نافس وشعار المدرسة، ومعلومات المعلمة والمادة والفصل، بالإضافة إلى رسوم بيانية وأرقام تفصيلية.

## التغييرات المطلوبة

### ملف واحد: `src/pages/teacher/ExamReport.tsx`

### 1. ترويسة التقرير المحسنة
- إضافة شعار نافس (`nafis-logo.png`) بجانب شعار المدرسة (`school-logo-65.png`)
- خلفية متدرجة مشابهة لهيدر الموقع (أخضر، أزرق، برتقالي) بنسخة مناسبة للطباعة
- عرض المعلومات التالية:
  - اسم المدرسة: "المتوسطة الخامسة والستون"
  - اسم المنصة: "منصة تدريب نافس"
  - اسم المعلمة (من جدول `profiles`)
  - المادة (من جدول `exams`)
  - الفصل/الفصول المستهدفة (من حقل `target_classes`)
  - التاريخ

### 2. إضافة البيانات والأرقام
- قسم ملخص الاختبار الحالي يبقى مع تحسين العرض
- إضافة جدول توزيع الدرجات بالشرائح الأربع (90-100%، 70-89%، 50-69%، أقل من 50%)
- إضافة أعلى وأدنى درجة

### 3. إضافة رسوم بيانية
- رسم بياني شريطي لتوزيع الدرجات (باستخدام recharts الموجودة)
- الرسوم تظهر في الطباعة باستخدام SVG (recharts تدعم ذلك تلقائياً)

### 4. جلب بيانات المعلمة
- جلب اسم المعلمة من جدول `profiles` باستخدام `teacher_id` من الاختبار
- جلب `target_classes` من جدول `exams`

### التفاصيل التقنية
- استيراد `nafis-logo.png` و `school-logo-65.png`
- جلب بيانات المعلمة: `supabase.from("profiles").select("name").eq("user_id", exam.teacher_id)`
- جلب `target_classes` مع بيانات الاختبار
- استخدام `recharts` (BarChart) لرسم بياني لتوزيع الدرجات
- CSS print styles موجودة مسبقاً في `index.css`
