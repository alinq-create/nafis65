
# تعديل استيراد بنك الأسئلة لدعم ملف الإكسل العربي

## ملخص
تحديث صفحة الاستيراد والدالة الخلفية لقراءة ملف الإكسل العربي كما هو، مع مطابقة مرنة لأسماء الأعمدة ومنع التكرار عند الاستيراد.

---

## المرحلة 1: تعديل `ImportQuestionBank.tsx`

### 1.1 دالة تطبيع اسماء الاعمدة
دالة `normalizeColumnName` تعالج الفروقات في كتابة اسماء الاعمدة:
- استبدال `_` بمسافة
- توحيد الهمزات (ا/أ/إ/آ/ؤ/ئ) الى `ا`
- ازالة التشكيل
- ازالة علامة الاستفهام `؟`
- ازالة المسافات الزائدة وتوحيدها

### 1.2 خريطة ربط الاعمدة
بعد التطبيع، يتم مطابقة كل عمود بحقله الداخلي:

```text
"رقم الصفحة"                -> page_number
"رقم السوال"                -> question_number
"نوع السوال"                -> question_type
"اسم صورة الصفحة الكاملة"   -> page_image_name
"اعلى الاطار"               -> frame_top
"يسار الاطار"               -> frame_left
"عرض الاطار"                -> frame_width
"ارتفاع الاطار"             -> frame_height
"الاجابة الصحيحة"           -> correct_answer
"يظهر للطالبات"             -> visible_to_students
"ملاحظات"                   -> notes
"المادة"                    -> subject
```

### 1.3 تحويل نوع السؤال
- اذا النص المطبّع يحتوي "اختيار" و"متعدد" -> يُحفظ كـ `"اختيار متعدد"`
- غير ذلك -> يُحفظ كـ `"إدخال"`

### 1.4 تحويل "يظهر للطالبات"
- "نعم" / "true" / "1" -> `true`
- "لا" / "false" / "0" / فارغ -> `false`
- القيمة الافتراضية: `true`

### 1.5 التحقق من وجود الصور
- بعد قراءة الاكسل واختيار الصور، يتم مقارنة `page_image_name` بقائمة الملفات المرفوعة
- اضافة حقل `image_missing` للعرض في المعاينة فقط
- عرض عدد الصور المفقودة في اعلى جدول المعاينة مع ايقونة تحذير

### 1.6 تحسين جدول المعاينة
الاعمدة المعروضة:

| العمود | الوصف |
|--------|-------|
| رقم الصفحة | من الاكسل |
| رقم السؤال | من الاكسل |
| النوع | بعد التحويل |
| اسم الصورة | مع ايقونة تحذير اذا مفقودة |
| الاطار | اعلى / يسار / عرض / ارتفاع |
| الاجابة | الاجابة الصحيحة |

### 1.7 تحديث `ParsedQuestion` interface

```text
ParsedQuestion {
  page_number: number
  question_number: number
  question_type: string
  page_image_name: string
  frame_top: number
  frame_left: number
  frame_width: number
  frame_height: number
  correct_answer: string
  visible_to_students: boolean
  notes: string | null
  subject: string
  image_missing?: boolean   // للمعاينة فقط
}
```

## المرحلة 2: تعديل الدالة الخلفية `import-question-bank`

### 2.1 استقبال الحقول الجديدة
- استقبال `visible_to_students` من البيانات المرسلة بدلا من تعيينها `true` دائما
- استقبال `subject` لكل سؤال من الاكسل (مع قيمة افتراضية "رياضيات")

### 2.2 منع التكرار (المفتاح الفريد)
قبل الادراج، يتم التحقق من عدم وجود سؤال بنفس (`subject` + `page_number` + `question_number`):
- استعلام قاعدة البيانات عن الاسئلة الموجودة بنفس المادة وارقام الصفحات
- تصفية الاسئلة المكررة واستبعادها
- اعادة عدد الاسئلة المكررة المتخطاة في الرد (`skippedCount`)

### 2.3 الحقول المحفوظة

```text
teacher_id, subject, page_number, question_number, question_type,
page_image_name, frame_top, frame_left, frame_width, frame_height,
correct_answer, visible_to_students, notes
```

## المرحلة 3: تحديث واجهة التقرير

- عرض عدد الاسئلة المتخطاة (المكررة) في تقرير الاستيراد
- اضافة بطاقة جديدة في التقرير توضح عدد المكررات التي تم تجاهلها
