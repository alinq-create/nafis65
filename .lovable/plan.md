

# إعادة تعيين كلمة مرور حساب المديرة

## ما سيتم تنفيذه
إعادة تعيين كلمة مرور حساب المديرة (admin) إلى `admin123` باستخدام Supabase Admin API.

## الخطوات التقنية

1. **إنشاء دالة خلفية مؤقتة** `reset-password` تقوم بـ:
   - استقبال `user_id` و `new_password`
   - التحقق أن الطالب هو مدير نظام أو مديرة
   - استخدام `adminClient.auth.admin.updateUserById()` لتغيير كلمة المرور

2. **استدعاء الدالة** لتغيير كلمة مرور المديرة (user_id: `165f07b1-a67d-4fdb-b3a3-e0ae82f3b32c`) إلى `admin123`

3. **بيانات الدخول بعد التعديل:**
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`
   - صفحة الدخول: `/login`
