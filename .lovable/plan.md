

# اضافة محرر قص الصور للمعلمة في بنك الاسئلة

## الفكرة العامة
عند ضغط المعلمة على معاينة سؤال مصور في بنك الاسئلة، يفتح محرر بصري يسمح لها بتعديل اطار القص (من اعلى واسفل) مع معاينة مباشرة للنتيجة. بعد الحفظ، تُحدث قيم `frame_top` و`frame_height` في قاعدة البيانات، ويظهر السؤال للطالبة بالقص الصحيح.

## المكونات المطلوبة

### 1. مكون محرر القص (`ImageCropEditor`)
ملف جديد: `src/components/teacher/ImageCropEditor.tsx`

- يظهر داخل Dialog عند ضغط المعلمة على معاينة السؤال المصور
- يعرض الصورة الكاملة للصفحة مع مستطيل قص شفاف قابل للسحب
- المعلمة تتحكم بـ:
  - **الحد العلوي**: سحب الحافة العلوية للاطار لاعلى او لاسفل
  - **الحد السفلي**: سحب الحافة السفلية للاطار لاعلى او لاسفل
  - **Slider بديل**: شريطي تحكم (من - الى) للتحكم الدقيق بنسبة القص العمودي
- معاينة مباشرة: تعرض الجزء المقصوص فقط بجانب الصورة الاصلية
- زر "حفظ" وزر "الغاء"

### 2. تعديل صفحة بنك الاسئلة (`QuestionBank.tsx`)
- المعاينة الصغيرة في الجدول تصبح قابلة للنقر (cursor-pointer)
- عند النقر تفتح Dialog تحتوي على `ImageCropEditor`
- بعد الحفظ يتم تحديث `frame_top` و`frame_height` في جدول `question_bank`
- يتم تحديث المعاينة المحلية مباشرة (optimistic update)

### 3. تعديل عرض الطالبة (`TakeExam.tsx`)
- لا تغيير جوهري - النظام الحالي يستخدم بالفعل `frame_top` و`frame_height` لعرض الصورة
- التعديلات التي تقوم بها المعلمة ستنعكس تلقائيا على عرض الطالبة

## التفاصيل التقنية

### مكون ImageCropEditor
```text
Props:
- imageUrl: string (رابط الصورة الكاملة)
- initialTop: number (0-1)
- initialLeft: number (0-1)  
- initialWidth: number (0-1)
- initialHeight: number (0-1)
- onSave: (top, left, width, height) => void
- onCancel: () => void

الواجهة:
- صورة كاملة مع overlay شفاف داكن خارج اطار القص
- اطار القص بحدود مرئية (dashed border)
- مقابض سحب على الحافة العلوية والسفلية
- شريطي Slider للتحكم الدقيق (اختياري اضافي)
- منطقة معاينة تعرض النتيجة النهائية
```

### تحديث قاعدة البيانات
لا حاجة لتعديل الجداول - الحقول `frame_top`, `frame_left`, `frame_width`, `frame_height` موجودة بالفعل في `question_bank` وتستخدم كنسب مئوية (0 الى 1).

### التعديل في QuestionBank.tsx
```text
- اضافة state لـ editingQuestion (السؤال المحدد للتعديل)
- المعاينة في الجدول تفتح Dialog عند النقر
- دالة handleSaveCrop تحدث question_bank عبر supabase.update
- تحديث محلي للقائمة بعد الحفظ
```
