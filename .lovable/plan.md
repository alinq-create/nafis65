

# تحليلات تشخيصية على مستوى الفصل والطالبة

## الملخص
تطوير قسم "تحليلات الفصول" في `ExamAnalytics.tsx` ليشمل تحليلاً تشخيصياً لكل فصل يوضح أقوى وأضعف الأسئلة، مع عرض أداء كل طالبة داخل الفصل على مستوى الأسئلة.

## التغييرات

### ملف واحد: `src/pages/teacher/ExamAnalytics.tsx`

### ما سيتغير في قسم تحليلات الفصول

بدلاً من عرض كروت ملخص فقط (عدد الطالبات، متوسط، أعلى، أدنى)، كل فصل سيحتوي على:

#### 1. ملخص الفصل (يبقى كما هو)
- عدد الطالبات، متوسط الدرجات، أعلى/أدنى درجة، نسبة النجاح

#### 2. أصعب 3 أسئلة في الفصل (جديد)
- جدول يعرض الأسئلة التي أخطأت فيها طالبات هذا الفصل أكثر من غيرها
- رقم السؤال (قابل للنقر للمعاينة)، نسبة الإجابة الصحيحة في هذا الفصل، عدد الخطأ

#### 3. أسهل 3 أسئلة في الفصل (جديد)
- الأسئلة التي أجابت عليها طالبات الفصل بشكل صحيح أكثر
- رقم السؤال، نسبة الإجابة الصحيحة

#### 4. جدول أداء الطالبات داخل الفصل (جديد)
- جدول يعرض كل طالبة في الفصل مع:
  - اسم الطالبة
  - الدرجة والنسبة
  - زر "عرض الملف" للانتقال لصفحة الطالبة

### كيف يعمل تقنياً

#### البيانات المطلوبة
- ربط `student_answers` بـ `student_attempts` لمعرفة أي طالبة (وبالتالي أي فصل) أجابت على كل سؤال
- توسيع استعلام `student_answers` ليشمل `attempt_id` حتى نستطيع ربطه بالفصل

#### المعالجة
1. بناء map يربط كل `attempt_id` بـ `class_number`
2. لكل فصل، حساب نسبة الصواب لكل سؤال من إجابات طالبات ذلك الفصل فقط
3. ترتيب الأسئلة تصاعدياً (أصعب 3) وتنازلياً (أسهل 3) لكل فصل
4. عرض النتائج في كروت موسعة بدلاً من الكروت المختصرة الحالية

#### الهيكل الجديد لبيانات الفصل

```text
ClassDetailedStats {
  classNumber: number
  studentCount, avgPct, highPct, lowPct, passRate  (موجود)
  hardest3: { questionId, questionOrder, sourceType, correctPct, wrongCount }[]  (جديد)
  easiest3: { questionId, questionOrder, sourceType, correctPct }[]  (جديد)
  students: { name, score, totalQ, pct }[]  (جديد)
}
```

#### التغييرات في الكود
- تعديل interface `ClassStats` ليشمل البيانات الجديدة
- تعديل حلقة بناء `classStats` (السطور 204-224) لتشمل تحليل الأسئلة لكل فصل
- توسيع استعلام `student_answers` ليشمل `attempt_id`
- تعديل عرض كروت الفصول (السطور 541-577) لتشمل الجداول الجديدة
- إزالة شرط `classMap.size > 1` ليظهر التحليل حتى لو كان فصل واحد
- الأزرار في جدول الأسئلة تستخدم نفس `openQuestionPreview` الموجودة

### ما لا يتغير
- الملخص العام (5 كروت)
- مؤشر فجوة الأداء
- توزيع الدرجات العام
- أصعب 5 وأسهل 3 على مستوى الاختبار الكامل
- جدول درجات الطالبات العام
- معاينة السؤال (Dialog)
- لا جداول جديدة في قاعدة البيانات
